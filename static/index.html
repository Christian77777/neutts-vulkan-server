OpenAI-Compatible Integration

This server provides a drop-in replacement for the OpenAI Audio Speech API (POST /v1/audio/speech).

Hermes Agent Configuration (config.yaml)

yaml 
tts:
  provider: openai
  openai:
    base_url: "http://<HOST_IP>:8090/v1"
    api_key: "local-neutts"
    model: "neutts"
    voice: "aelita"
  use_gateway: false

Curl Streaming Command

bash 
curl -s -N -X POST http://localhost:8090/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "input": "Hello! Testing live streaming audio.",
    "response_format": "mp3",
    "stream": true
  }' | mpv --no-terminal -

Python OpenAI SDK

python 
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8090/v1", api_key="local")

with client.audio.speech.with_streaming_response.create(
    model="neutts",
    voice="aelita",
    input="Hello from Python SDK.",
    response_format="pcm"
) as response:
    for chunk in response.iter_bytes():
        # Process raw 24kHz 16-bit PCM chunk
        pass
