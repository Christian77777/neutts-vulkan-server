# Voices Directory (Persistent Volume)

This directory stores cached voice references. In Docker deployments, this directory is mounted into the container as a persistent volume at `/app/voices`.

Voices can be added, updated, or removed at any time **without rebuilding or restarting the Docker container**.

## Adding Voices

### Method 1: Web Management Portal (Easiest)
Navigate to `http://localhost:8090/`, go to **Clone Voice**, upload a short audio clip (3–10s), enter its transcript, and click **Encode Voice**.

### Method 2: REST API
```bash
curl -X POST http://localhost:8090/v1/audio/voices \
  -F "name=my_voice" \
  -F "text=Exact spoken transcript here." \
  -F "audio_file=@/path/to/my_voice.wav"
```

### Method 3: Pre-Encoding Utility CLI
```bash
python cache_reference.py \
    --audio /path/to/my_voice.wav \
    --text "Exact spoken transcript here." \
    --name my_voice
```

## File Format

Each voice consists of two files sharing the same base name:
1. `<voice_name>.pt`: Pre-computed reference token tensor generated by NeuTTS reference encoder.
2. `<voice_name>.txt`: Exact plain text transcript matching the reference audio.

## Calling a Voice via API

Specify the voice name in your API request:
```bash
curl -X POST http://localhost:8090/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "neutts",
    "input": "Testing my custom voice clone.",
    "voice": "my_voice",
    "response_format": "mp3"
  }'
```

List all available voices:
```bash
curl http://localhost:8090/v1/audio/voices
```
